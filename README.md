# 🎓 Universal GPA and CGPA Calculator – Level 2

## 📌 Introduction

Universal GPA and CGPA Calculator – Level 2 is an advanced version of the project, designed to simplify student result processing and class-wise academic performance analysis.

It supports bulk result uploads, subject-credit matching, editable student records, and automated GPA and CGPA calculations.

## 🚀 Features

- Upload student results using supported file formats.
- Import subject codes, names, and credits separately.
- Extract student details into editable records.
- Automatically match subject codes with credits.
- Identify missing or unmatched subject information.
- Calculate individual semester GPA and CGPA.
- Perform class-wise student performance analysis.
- Export student results as CSV files.
- Save data locally using browser Local Storage.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- vs code

## 🎯 Objective

To provide an advanced academic management solution that simplifies bulk student result processing and supports class-level academic performance analysis.
